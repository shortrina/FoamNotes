
# React

## What is React?

React is a JavaScript library for building user interfaces, particularly for single-page applications (SPAs) where the interface needs to be updated dynamically without a full page reload.    

## 📌 Key Features

- **Component-Based Architecture:** React allows you to break down your UI into reusable components, making it easier to manage and maintain the codebase.
- **Virtual DOM:** Instead of directly manipulating the browser's DOM, React uses a virtual DOM to optimize updates and improve performance.
- **One-Way Data Flow:** React follows a unidirectional data flow, making it easier to reason about the state of your application.
- **Declarative Syntax:** You describe what the UI should look like, and React handles the updates to make it match.
- **Large Ecosystem:** React has a vast ecosystem of libraries and tools, including state management libraries (e.g., Redux) and UI libraries (e.g., Material-UI, Ant Design).
- **Cross-Platform:** React can be used to build both web and mobile applications, with the help of frameworks like React Native.

## 🧠 Major Concepts of React
### Programmatic React Features
- **Hooks:** Use different React features from your components.
- **components:** Built-in components that you can use in your JSX.
- **APIs:** APIs that are useful for defining components.
- **Directives:** Provide instructions to bundlers compatible with React Server Components.

### React DOM
React DOM contains features that are only supported for web applications(which run in the browser DOM environment).This section is broken into the following sub-sections:
- **Hooks:** Hooks for web applications which run in the browser DOM environment.
- **components:** React supports all of the browser built-in HTML and SVG components.
- **APIs:** The `react-dom` packages contains methods supported only in web applications.
- **Client APIs:** The `react-dom/client` APIs let you render React components on the client(in the browser).
- **Server APIs:** The `react-dom/server` APIs let you render React components to HTML on the server.
- **Static APIs:** The `react-dom/static` APIs let you generate static HTML for React components.
